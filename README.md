# PilgrimRoute AI

PilgrimRoute AI is a client-side thematic multi-destination pilgrimage
route planner.

## Features

- 12 Jyotirlingas of Lord Shiva
- Starting location selection
- Geographic clustering
- Nearest-neighbor route ordering
- 2-opt route optimization
- Interactive Leaflet map
- Numbered pilgrimage markers
- Step-by-step itinerary
- Estimated distance per leg
- Generic transit search links
- Responsive design
- GitHub Pages compatible
- No backend
- No API key
- No database
- No server required

## Technology

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Leaflet.js
- OpenStreetMap
